# molecular-geometry-audit

分子构象几何核查工具。读取构象坐标 CSV 与拓扑 JSON，计算局部几何测量（键长、键角、扭转角）、整体大小（质量中心、质量加权回转半径）以及与参考构象的原子对距离差异，定位可疑结构。仅使用 Python 标准库，不依赖任何化学数据库，不推测键或键级。

## 调用方式

```
python -m molecular_geometry --topology examples/topology.json --coordinates examples/coordinates.csv --unit angstrom --config examples/config.json --output-dir out
```

输入错误时以非零码退出，且不生成或覆盖任何报告；单项测量未定义属于正常分析结果，不影响其他测量。

## 输入格式

- 拓扑 JSON：`{"atoms": [{"id": "C1", "mass": 12.011}, ...], "bonds": [["C1", "C2"], ...]}`。原子编号为非空字符串，质量为正的有限数；键为无向边，拒绝空拓扑、重复原子、自连键、重复键（颠倒端点视为同一条）和未知原子。
- 坐标 CSV：列 `conformer,atom,x,y,z`。每个构象必须恰好覆盖拓扑中的全部原子，拒绝空表、重复行、缺失原子和非有限坐标。
- `--unit`：`angstrom` 或 `nm`，输入统一换算为埃（1 nm = 10 Å）。
- 配置 JSON：`{"reference_conformer": "<已存在的构象编号>"}`。

## 几何口径

- 键长：拓扑中每条键两端原子的欧氏距离（埃），允许为零。
- 键角：相邻两键从中心原子向外的夹角（度）。
- 扭转角：四个不同原子构成的全部三键链的无符号扭转角（度），取沿链方向前两键叉积与后两键叉积的夹角，范围 0–180；反向链只报告一次，以原子编号序列较小者为准。
- 零长键使相关角度未定义；连续三原子共线使该链扭转角未定义。未定义项输出 `null`（CSV 中为空值）并附原因，不以零角替代，不输出 NaN。
- 质量中心与回转半径均按质量加权；回转半径为各原子到质量中心的距离平方按质量加权平均后开方，不使用几何中心。
- 参考差异：全部无序原子对距离与参考构象对应距离之差的均方根，并报告绝对差最大的原子对（并列按编号字典序取先）。该指标基于距离，平移或旋转构象不改变其值，也不直接比较未经对齐的坐标；它不是手性鉴别手段，也不是能量评价。少于两个原子时返回 `null` 并说明原因。

## 输出

输出目录中生成两个文件（均按构象及原子编号字典序排序）：

- `geometry.csv`：`conformer,kind,atoms,value,reason`，逐条测量，长度单位为埃、角度单位为度；未定义项 `value` 为空、`reason` 说明。
- `analysis.json`：每个构象的质量中心、回转半径、各类测量的有效/未定义数量、键长与有效键角的 min/max/mean（无有效值时为 `null`），以及相对参考构象的差异指标。

## 示例与测试

`examples/` 提供三种典型情况：直线结构（共线导致扭转角未定义）、坐标重合（零长键导致键角未定义）、刚体变换（差异指标为零）。

```
python -m unittest discover -s tests
```
